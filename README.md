# 🛒 Product Management System with Groq AI

An AI-powered Product Management System built using **Python**, **Gradio**, and **Groq LLM API**. This application provides an interactive interface to manage products while leveraging Generative AI for intelligent product-related operations.

---

## 📌 Project Overview

The Product Management System is designed to simplify product management by providing an easy-to-use interface for performing common operations such as adding, viewing, updating, and deleting product information.

The project integrates the **Groq AI API** to demonstrate the use of Large Language Models (LLMs) in modern business applications.

---

## ✨ Features

- 📦 Add New Products
- 📋 View Product List
- ✏️ Update Product Information
- ❌ Delete Products
- 🤖 AI Integration using Groq LLM
- 🖥️ Interactive Gradio User Interface
- 📊 Simple and User-Friendly Dashboard

## ⚙️ Installation

### Clone the repository

```bash
git clone https://github.com/yourusername/Product-Management-System-with-Groq-AI.git
```

### Navigate to project folder

```bash
cd Product-Management-System-with-Groq-AI
```

### Install dependencies

```bash
pip install -r requirements.txt
```

### Create a `.env` file

```
GROQ_API_KEY=your_api_key_here
```

### Run the application

```bash
python gui.py
```
